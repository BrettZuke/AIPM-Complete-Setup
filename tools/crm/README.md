# The CRM moved

The CRM lives in its own repo now: **aipm-crm**, next to this one on GitHub. It is
the CRM from the demo: pipeline, power dialler, sequences, sending through Resend
or your own Gmail, replies, the assistant, the Build button, referrals, customers
and the thank-you page, on a database of your own instead of a sheet.

Clone it and follow `dashboard/README.md` there. One command puts it live. Nothing
else is needed from this folder.
